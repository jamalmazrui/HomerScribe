What’s New in HomerScribe

It now describes photographs, and reads a film’s own captions

Windows installer · Project on GitHub

HomerScribe describes video and transcribes speech on your own computer, without sending anything anywhere. It is free and open source. Two things have been added since I last wrote about it.

It describes a folder of photographs

Point it at a zip file of pictures instead of a video, and it looks at each one and writes down what it sees.

You get each picture back with the description written inside the file — not in a note beside it, but in the picture, where it travels with the file wherever you send it. Select one in Windows Explorer, open Properties, and the description is simply there for a screen reader to read.

You also get described.zip: the same pictures under new names. IMG_4471.JPG becomes Elderly woman in a blue floral dress beside a dry stone wall.jpg.

Photographs from an iPhone work too, in the .heic format it saves them as.

It uses what you can tell it. A picture called Jeannie & Jim - Lake Tahoe.jpg gets those names, because somebody who was there typed them. You can drop a note into the zip saying who tends to appear and how to tell them apart. It will not name anyone it cannot match to what is in front of it.

Forty-nine photographs took under three minutes.

It reads a film’s own captions

Many films already carry their words. Where a person wrote those captions, HomerScribe now uses them instead of listening to the film.

A person’s captions are better than anything a machine makes, and not only at the words. They say who is speaking. They write down what can be heard but not spoken — a door slamming, music starting, laughter. For someone who can neither see nor hear a film, that is the part nothing else provides.

If you only want the words, it no longer downloads the film at all. Four videos, transcribed, in under a minute.

Captions a machine made are another matter, and HomerScribe can tell the difference. YouTube’s automatic ones have no speaker and no sounds, so it listens to the film instead and writes better sentences.

Try it

  • Windows installer
  • Project on GitHub

Accept the defaults and let the installer fetch the models. That is the long part, and it happens once. There is a sample video in the box, so you can press OK and watch it work straight away.

Transcription is the stronger half; description is harder, and I would rather you saw that for yourself than took my word for it. Tell me where it goes wrong.
